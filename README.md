# DevConnect

Landing page responsiva desenvolvida com HTML5, CSS3, JavaScript e Bootstrap 5.

## Sobre o projeto

O DevConnect é uma landing page voltada à apresentação de cursos e conteúdos de programação, com uma interface moderna, navegação intuitiva e formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Funcionalidades

- Menu de navegação
- Seção de apresentação
- Carrossel de cursos
- Formulário de contato
- Rodapé personalizado

## Objetivo

Praticar desenvolvimento Front-End, estruturação semântica com HTML, estilização com CSS, componentes do Bootstrap e responsividade.

## Desenvolvedor

Projeto desenvolvido para fins de estudo e aprimoramento das habilidades em desenvolvimento web.
